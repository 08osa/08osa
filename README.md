## ⭐ Featured

### [Intelligent Real-Time Arabic Sign Language Translation](https://github.com/08osa/arabic-sign-language-translation)
Continuous sign-language video goes through MediaPipe keypoints, then idle-based segmentation and a BiLSTM classifier. An LLM refines the result and TTS speaks it in Arabic. **92.07 %** accuracy on 50 sentence classes, running in real time.
